# 02 — User Personas

Empat persona awal untuk Warung Apex. Dipakai sebagai acuan desain UI/UX dan
penulisan copy.

## 2.1 Persona 1 — "Arya", Pembeli Gadget Muda

| Atribut | Detail |
|---|---|
| Usia | 20–28 tahun |
| Pekerjaan | Mahasiswa / fresh graduate |
| Perangkat | Smartphone Android (utama), laptop |
| Quote | "Gue cek harga dulu dari HP, buru-buru." |

- **Goals**: menemukan produk perangkat yang diinginkan dengan cepat, lihat
  foto jelas, tahu kisaran harga.
- **Pain points**: website lambat di HP, gambar kecil, harga tidak terlihat.
- **Kebutuhan**: katalog cepat, gambar besar, harga jelas.

## 2.2 Persona 2 — "Bu Ratna", Pembeli Umum

| Atribut | Detail |
|---|---|
| Usia | 40–55 tahun |
| Pekerjaan | Ibu rumah tangga / pedagang |
| Perangkat | Smartphone kelas menengah |
| Quote | "Saya mau beli untuk anak saya, takut salah pilih." |

- **Goals**: melihat produk dengan tenang, yakin dengan pilihan.
- **Pain points**: istilah teknis membingungkan, tidak ada penjelasan singkat.
- **Kebutuhan**: tampilan sederhana, deskripsi mudah dipahami, kontak jelas.

## 2.3 Persona 3 — "Dimas", Reseller / Dropshipper

| Atribut | Detail |
|---|---|
| Usia | 25–35 tahun |
| Pekerjaan | Reseller produk gadget |
| Perangkat | Smartphone + laptop |
| Quote | "Gua butuh info produk yang bisa gua share ke pembeli gua." |

- **Goals**: mengakses informasi produk yang akurat dan siap dibagikan.
- **Pain points**: data produk tidak lengkap, gambar kualitas rendah.
- **Kebutuhan**: halaman produk rinci, kualitas gambar tinggi, data konsisten.

## 2.4 Persona 4 — "Pak Johan", Owner / Admin (Internal)

| Atribut | Detail |
|---|---|
| Usia | 30–50 tahun |
| Peran | Pemilik toko |
| Perangkat | Laptop |
| Quote | "Yang penting simpel, katalog saya gampang diupdate." |

- **Goals**: mudah memperbarui daftar produk.
- **Pain points**: proses update rumit, butuh developer setiap kali ganti.
- **Kebutuhan (v1)**: data produk tersentralisasi di satu file agar mudah
  diubah; panel admin `[PROPOSAL]` di versi lanjutan.

## 2.5 Prioritas Persona

1. Arya (pembeli muda) — mayoritas traffic.
2. Bu Ratna (pembeli umum) — butuh kesederhanaan.
3. Dimas (reseller) — butuh kelengkapan data.
4. Pak Johan (admin) — didelegasikan ke roadmap lanjutan.
